# On keeping a sentence in the room

Most reading software tries to be a library, a highlighter, a social network, and a dashboard at the same time. The page becomes a place you visit, not a place you stay.

Locked In is built around a simpler bet: if the sentence is held still, the rest of the product can be quiet.

You can import a file, save a webpage, or start from this essay. The same document can be read as a page, flashed one word at a time, or spoken aloud. Highlights attach to the document itself — a block and an offset — not to whatever the browser happened to draw today.

Speed reading here is not a gimmick. RSVP and ORP exist because the eye already knows where to land in a word. The copper line you will see in the speed reader is that landing mark. It does not move. The word moves around it.

Nothing in this file has left your machine. There is no account required to finish it. If you want cloud later, that is a choice you make after the reading is already yours.

## A working loop

Open a document. Read until something is worth keeping. Mark it. Close the laptop. Tomorrow, continue from the same offset.

That loop is the product. Search and questions come after it, never before it.

## Keyboard

- `⌘K` command menu
- `Space` play and pause in speed reading
- `←` `→` step a word
- `F` focus the page
- `Esc` leave focus

Read the next paragraph slowly, then press Speed and watch the same sentence lock to the aperture.

The development of attention is mostly the development of refusal: refusing the extra pane, the extra metric, the extra glow around a button that does not help you keep the sentence in the room.
