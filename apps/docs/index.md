# Locked In Reader

Read faster. Listen anywhere. Remember everything. Own your knowledge.

Locked In is a local-first reading OS. The PWA and Chrome extension are clients of the same TypeScript core.

- Import Markdown, TXT, HTML, EPUB, and PDF
- Read, speed-read (RSVP / ORP / chunk / guided), and listen
- Highlight, note, and search without an account
- Optional SpaceXAI or Ollama for grounded answers
